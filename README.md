# 🏥 Health Data Analyzer

A simple Health Data Analysis web application built using **Python**, **Pandas**, **Matplotlib**, and **Gradio**.

## Features

- 📂 Upload CSV datasets
- 👀 Dataset Preview
- 📊 Dataset Information
- ❗ Missing Value Analysis
- 📈 Summary Statistics
- 📉 Histogram Visualization
- 🔥 Correlation Heatmap

## Tech Stack

- Python
- Pandas
- Matplotlib
- Gradio
