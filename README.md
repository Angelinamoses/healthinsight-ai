# 🏥 HealthInsight AI

### Clinical Dataset Explorer & Quality Assessment Dashboard

HealthInsight AI is a web-based healthcare data analysis application developed using **Python** and **Gradio**. The application performs **Exploratory Data Analysis (EDA)** on clinical datasets by providing statistical summaries, data quality assessment, visualizations, and automated clinical insights.

This project demonstrates how healthcare datasets can be explored quickly through an interactive dashboard without writing SQL queries or complex analysis code.

---

## 🎯 Project Objective

The primary objective of this project is to simplify healthcare data exploration by allowing users to upload a CSV dataset and automatically generate meaningful insights.

The application helps users:

- Analyze healthcare datasets
- Evaluate dataset quality
- Identify missing values
- Visualize numerical data
- Explore feature correlations
- Generate human-readable clinical insights
- Download a summary report

## 📊 Application Modules

### 1. Dataset Upload

Uploads a healthcare dataset in CSV format.

### 2. Dataset Overview

Displays:

- Number of Records
- Number of Features
- Missing Values
- Duplicate Records
- Memory Usage

### 3. Data Quality Assessment

Calculates an overall dataset quality score based on missing values and duplicate records.

### 4. Statistical Analysis

Generates descriptive statistics using Pandas.

### 5. Data Visualization

Creates:

- Histogram
- Correlation Heatmap

### 6. Clinical Insights

Automatically generates human-readable observations from the uploaded dataset.

### 7. Report Generation

Allows users to download the complete analysis report.
